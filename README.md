# 2028 수험생활 통합 관리

GitHub Pages에서 실행되는 개인 학습 관리 PWA입니다. 데이터는 브라우저 IndexedDB에 저장됩니다.

## 추가 기능

### 기간별 할 일
- 시작일과 종료일을 지정해 기간 목표를 저장합니다.
- 7일·14일·30일 빠른 설정 또는 직접 날짜 입력을 지원합니다.
- 진행 중·시작 예정·기간 종료 미완료·완료 상태로 구분합니다.
- 수정·완료 체크·삭제를 지원하며 삭제 항목은 기존 휴지통에서 복구할 수 있습니다.

### 보물상자
- 기본 잠금 해제일은 교육부가 발표한 2028학년도 수능 성적 통지일인 **2027-12-10**입니다.
- 해제 날짜는 화면에서 변경할 수 있습니다.
- 잠금 기간에 보관한 소원은 AES-GCM(Web Crypto API)으로 암호화해 IndexedDB에 저장합니다.
- 잠금 화면에는 저장된 소원 내용이나 목록을 표시하지 않습니다.
- 설정한 날짜가 되면 자동으로 잠금이 해제되고, 모든 소원을 공개합니다.
- 공개 후 소원별 완료 체크를 지원합니다.

## 데이터베이스 변경

- 기존 데이터베이스 이름 `examLife2028`를 유지합니다.
- 기존 버전 3에서 버전 4로 점진 업그레이드합니다.
- 새 저장소 `dailyStudy`를 추가합니다. 기존 v3의 `periodTasks`, `wishVault`도 유지합니다.
- 기존 저장소 및 기록은 삭제·초기화하지 않습니다.
- v2 이하의 예전 백업에는 새 저장소가 없으므로, 해당 백업을 `교체 복원`하더라도 백업에 포함되지 않은 새 저장소는 유지합니다.
- 신규 저장소도 이후 백업·복원 대상에 포함됩니다.

## 암호화 및 잠금의 한계

보물상자 내용은 AES-GCM 암호문으로 저장되며 일반 잠금 화면에서는 복호화하거나 렌더링하지 않습니다. 자동 해제와 백업·복원을 지원하기 위해 암호화 키도 같은 기기의 IndexedDB 설정에 저장되며, 일반 데이터 백업에도 암호화 키가 포함됩니다. 따라서 백업 파일을 다른 사람과 공유하지 마세요. 이는 일반 화면이나 저장 데이터에서 평문이 노출되는 것을 줄이는 보호 장치이지, 개발자 도구·브라우저 프로필 탈취·기기 자체 접근을 막는 보안 경계는 아닙니다.

잠금 해제 날짜는 브라우저의 기기 날짜를 기준으로 검사합니다. 기기 시각 변경, 개발자 도구, 소스 수정 또는 IndexedDB 직접 변경을 통한 우회를 완전히 차단할 수는 없습니다. 서버를 사용하지 않는 GitHub Pages 앱의 구조적 한계입니다.

## 배포

저장소의 GitHub Pages 게시 루트에 ZIP 안의 파일 전체를 올립니다. 특히 `index.html`, `app.js`, `db.js`, `features.js`, `styles.css`, `sw.js`가 같은 폴더에 있어야 합니다. `sw.js`의 캐시 버전은 `exam-life-shell-v2.0.0`입니다.

아이패드 Safari에서 이전 화면이 계속 보이면 사이트를 다시 로드하고, 홈 화면에 설치된 PWA라면 앱을 완전히 종료한 뒤 다시 실행하세요. 저장된 기존 기록은 같은 사이트 주소와 브라우저 프로필의 IndexedDB에 그대로 유지됩니다.


## 추가된 기록 기능 (v4)

- 월간 달력과 Google 캘린더 형태의 24시간 주간 시간표를 제공합니다. 주간 시간표는 00:00부터 24:00까지 표시하며 일정 블록을 눌러 수정할 수 있습니다.
- 월간 달력의 하루 칸은 직접 입력한 하루 공부 시간에 비례해 사용자가 선택한 색으로 진해집니다. 날짜를 누르면 그날의 O/X/△ 공부 기록과 입력 시각을 확인할 수 있습니다.
- 공부 기록은 과목·공부 내용·O/X/△ 결과 중심이며, 공부 시간은 선택 입력입니다.
- 주요 모의고사 성적은 과목별 원점수·표준점수·백분위·등급 추이를 그래프로 확인할 수 있습니다.
- 신규 기록에는 `inputAt` ISO 시각을 함께 저장합니다. 기존 데이터는 기존 `createdAt`을 입력 시각으로 활용해 표시합니다.
- 모든 주요 기록 저장소(공부, 일정, 시험, 주요 모의고사, 교재, 식사, 운동, 일기, 기간별 할 일, 보물상자, 하루 공부 시간)에 입력 시각을 기록합니다.

## 개인 백업 가져오기

개인 기록 백업 JSON을 공개 GitHub 저장소의 소스 파일로 포함하지 마세요. 백업에는 성적과 생활 기록이 포함될 수 있습니다. 사이트 배포 후 **백업 · 복원 → 백업 JSON 파일 선택 → 병합 복원**을 사용하면 기존 기록은 덮어쓰지 않고 동일 ID가 없는 항목만 추가할 수 있습니다. 복원 방식은 반드시 `병합 복원`을 선택하세요.


## 공개 학습 아카이브

`공개 학습 아카이브` 메뉴에서 공개할 데이터 종류와 날짜 범위를 직접 선택한 뒤 미리보기 및 HTML 내보내기를 할 수 있습니다. 생성된 `my-study-archive.html`은 별도의 정적 페이지이며 자동 업로드되지 않습니다. 일기, 식사, 운동, 시간표, 개인 일정, 보물상자, 내부 ID, 입력 시각, 메모, 사진은 공개 파일에서 제외됩니다. GitHub Pages에 게시하기 전에 내보낸 HTML을 직접 열어 내용을 검토하고, 공개해도 되는 정보만 포함됐는지 확인하세요. 공개된 페이지는 누구나 복사하거나 저장할 수 있습니다.


## 전체 수험생활 공개 아카이브

공개 학습 아카이브는 공부·시간표·기간별 목표·모의고사·교재·식사·운동·일기 기록을 별도 HTML로 내보냅니다. 설정, 감사 로그, 휴지통, 암호화 키, 보물상자 암호문, 사진 및 입력 시각은 내보내지 않습니다. 이메일·전화번호·식별번호 형태와 주소/좌표 필드는 필터링하지만 자유 입력 문장에 포함된 이름·학원명·생활 동선은 자동으로 완벽히 판별할 수 없으므로 게시 전에 HTML을 직접 검토해야 합니다. 원본 IndexedDB는 내보내기 과정에서 변경하지 않습니다.

## v1.9.0

- 공부 잔디, 레벨·경험치, 부엉이 5단계 성장, 7일 백업 알림, 공부 분석, 50분 집중/10분 휴식, 수능 D-Day 강화, 하루 공부 결산을 추가했습니다.

- 경험치와 잔디는 저장된 공부 기록을 다시 계산합니다. 실전 타이머가 만든 공부 기록과 시험 성적을 두 번 더하지 않습니다.
- 하루 공부 결산은 일기와 따로 저장되며 공개 학습 아카이브에 포함되지 않습니다.
- 서비스워커 캐시 버전은 `exam-life-shell-v1.9.0-r2`입니다. `db.js`와 데이터베이스 이름·버전은 바꾸지 않았습니다.

- 공부 분석은 일간·주간·월간·전체와 최근 7·30·90·365일을 같은 공부 기록으로 봅니다.
